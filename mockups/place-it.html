What this mock-up shows, and where it lands in the app

  • Tab 1 is the new Movable pieces section under Draw in public/sets.html (new public/modeledit.js). Two views like Sort: Answer key (drag each piece to where it belongs; the dashed ring is how close counts) and Student start (drag to set the scattered start).
  • Tab 2 adds a Pieces tool to the student rail in public/index.html. Pieces move only in that tool; the pen and arrow draw over them. Keyboard: Tab to a piece, arrow keys move it (Shift for bigger steps), and a live region says where it went.
  • Tab 3 draws the same board through paintBoard, plus rings from the key that only the teacher sees. Results reuse the Sort results panel.
  • Rotation is shown disabled (Later): Phase C. Picture cut-outs are also Phase C; version 1 has labels and built-in pictures.
